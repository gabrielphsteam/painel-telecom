# Painel Telecom

Painel de reparos (BAs) publicado via GitHub Pages.

- `index.html`: o painel (arquivo único).
- `atividades.csv`: dados já sem informações pessoais; o painel lê este arquivo sozinho e recarrega a cada 10 min.

Para atualizar: substitua o `atividades.csv` por um novo (mesmo nome).
